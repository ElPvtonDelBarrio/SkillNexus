## Organización

- Assets/Scenes: escenas del proyecto.
- Assets/Scripts: código del sistema.
- Assets/UI: recursos de la interfaz.
- Assets/Data: datos locales de prueba.
- Packages: dependencias del proyecto.
- ProjectSettings: configuración de Unity.

## Cómo abrir el proyecto

1. Aceptar la invitación al repositorio privado.
2. Clonar el repositorio con GitHub Desktop.
3. Instalar Unity 6000.6.3f1 mediante Unity Hub.
4. En Unity Hub, añadir el proyecto desde el disco seleccionando
   la carpeta que contiene Assets, Packages y ProjectSettings.
5. Abrir el proyecto y esperar a que termine la importación.
6. Abrir Assets/Scenes/MainScene.unity.

## Trabajo en equipo

1. Actualizar main antes de comenzar.
2. Crear una rama para la tarea.
3. Realizar los cambios y hacer commit.
4. Publicar la rama o subir los cambios con push.
5. Crear una Pull Request hacia main.
6. Revisar los cambios y hacer merge.
7. Actualizar main en las computadoras del equipo.

Los archivos .meta deben subirse junto con sus recursos.
Las carpetas Library, Temp, Logs y Obj quedan excluidas mediante
.gitignore.
